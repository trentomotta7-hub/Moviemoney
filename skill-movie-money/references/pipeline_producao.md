# Pipeline de produção — redirecionamento obrigatório

Este documento foi substituído pelo pipeline auditado em:

`../skills/moviemoney-production/references/pipeline_ponta_a_ponta.md`

Não usar o fluxo antigo de cinco etapas, pois ele permitia montar e entregar vídeos sem dossiê de mineração, manifesto de takes, gate técnico executável, certificado perceptual, revisão de claims e checksum de entrega.

Antes de produzir qualquer criativo:

1. Ler `../skills/moviemoney-production/SKILL.md`.
2. Executar o pipeline ponta a ponta.
3. Produzir um master `CANDIDATE`.
4. Aprovar o gate técnico e o certificado perceptual.
5. Somente então promover para `APPROVED` e entregar.
