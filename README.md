# Moviemoney

Backup completo do projeto **Movie Money** — máquina de produção de criativos de venda (UGC e POV) para TikTok Shop e plataformas de venda via VSL, produzida 100% dentro da Manus.

## Estrutura do Repositório

| Pasta | Conteúdo |
|-------|----------|
| `skill-movie-money/` | A skill Manus completa do projeto (SKILL.md + referências + assets) |
| `skill-movie-money/SKILL.md` | Documento principal da skill, com regras e fluxo de produção |
| `skill-movie-money/references/checkpoint.md` | Checkpoint atualizado do estado do projeto e backlog |
| `skill-movie-money/references/elenco.md` | Perfis completos dos 5 personagens (visual, personalidade, tom de voz, nichos) |
| `skill-movie-money/references/pipeline_producao.md` | Pipeline passo a passo de produção de criativos |
| `skill-movie-money/templates/personagens/` | Imagens-base oficiais dos 5 personagens |
| `skill-movie-money/templates/cenas/` | Banco de cenas: 20 cenários (4 por personagem) |
| `docs_projeto/` | Documentos originais do projeto (elenco e definição de cenários) |

## Como Restaurar a Skill na Manus

Em uma nova sessão da Manus, basta pedir para clonar este repositório e copiar a pasta `skill-movie-money/` para `/home/ubuntu/skills/movie-money/`, ou anexar o repositório via integração GitHub. A skill contém todo o contexto necessário para continuar o projeto de onde parou.

## Estrutura Narrativa dos Criativos

Todo criativo segue: **Hook fortíssimo (0–4s) → Problema → Causa → Solução → CTA forte**, em vídeos verticais 9:16 com lip sync real (UGC) ou câmera em primeira pessoa (POV).
