## Estratégia do Elenco

O elenco foi desenhado para cobrir os principais perfis de consumidor do TikTok Shop e das plataformas de venda por VSL. Cada personagem atinge um público e um nicho diferente, de modo que **qualquer produto minerado terá pelo menos dois personagens ideais para vendê-lo**. A diversidade não é estética — é estratégica: idade, gênero, tom e energia foram escolhidos para maximizar a identificação do público com o relato de "venda invisível".

## Regras de Uso do Elenco

**Seleção por produto.** Para cada produto minerado, selecionar um ou dois personagens com base no nicho e no público-alvo do produto. Nunca escalar um personagem fora do perfil dele — isso quebra a autenticidade, que é o ativo mais valioso do formato UGC.

**Consistência visual.** As imagens deste documento são as **imagens-base oficiais** de cada personagem. Todo vídeo UGC gerado deve usar a imagem-base correspondente como referência de identidade, mantendo rosto, estilo de roupa, cenário e iluminação consistentes. Isso cria reconhecimento e confiança do público ao longo do tempo.

**Rotação e teste A/B.** Em campanhas com múltiplos criativos para o mesmo produto, usar personagens diferentes para testar qual perfil performa melhor com o público daquele produto. O vencedor recebe as variações de hook seguintes.

**Casamento com o framework de roteiro.** Cada personagem abre o vídeo com seu hook-assinatura (ou variação dele) nos 4 segundos iniciais, seguindo a estrutura padrão da Movie Money: **Hook (0–4s) → Problema → Causa → Solução (produto) → CTA forte**.
